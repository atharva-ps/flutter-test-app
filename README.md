# Flutter Test App for JustBaat Ads Plugin

This is a standalone Flutter application to test the JustBaat Ads Flutter plugin.

## Setup

1. **Navigate to the test app directory:**
   ```bash
   cd flutter_test_app
   ```

2. **Get dependencies:**
   ```bash
   flutter pub get
   ```

3. **Run the app:**
   ```bash
   flutter run
   ```

## Features Tested

- ✅ Banner Ads
- ✅ Interstitial Ads
- ✅ Rewarded Ads
- ✅ Native Ads
- ✅ App Open Ads

## Configuration

Make sure your ad configuration is set up at:
`https://ads-sdk.pages.dev/sample-test-new/config.json`

The app uses the company ID: `sample-test-new`

## Notes

- This app uses the plugin from the local path: `../flutter_plugin`
- Make sure the plugin is properly built before running this app
- The app handles lifecycle events automatically
